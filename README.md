# smart-car
Проект представляет собой систему управления роботизированной платформой на базе микроконтроллера с использованием компьютерного зрения. Библиотека Python MediaPipe используется для отслеживания положения руки, а обученная модель машинного обучения распознает жесты и преобразует их в команды управления устройством.

## Cуть работы проекта
1. Камера захватывает изображение в реальном времени.
2. MediaPipe определяет положение руки и пальцев.
3. Обученная модель машинного обучения распознает жест.
4. Команда отправляется на устройство.
5. Устройство выполняет движение.

## Установка
```bash
git clone https://github.com/margosha-soso/smart-car
cd smart-car
pip install -r requirements.txt
```

## Запуск проекта
```bash
python main.py
```
Перед запуском убедитесь, что:
- подключена камера
- загружена обученная модель
- включено устройство управления

## Поддерживаемые жесты

| Жест | Описание | Команда | Действие |
|------|----------|:-------:|----------|
| Открытая ладонь | Пальцы полностью выпрямлены и разведены | **F** | Движение вперёд |
| Сжатый кулак | Все пальцы согнуты | **B** | Движение назад |
| Большой палец направлен влево | Остальные пальцы согнуты | **L** | Поворот влево |
| Большой палец направлен вправо | Остальные пальцы согнуты | **R** | Поворот вправо |
| Отсутствие руки или команда остановки | Рука не обнаружена или жест не распознан | **S** | Остановка робота |
